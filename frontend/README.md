## Getting Started

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Frontend

This is the user interface for the Skylark Drones BI Agent, built with a modern web stack to provide a fast, responsive, and seamless chat experience.

### Tech Stack
- **Framework**: [Next.js](https://nextjs.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) for a minimal like aesthetic
